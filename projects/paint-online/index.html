Paint Online - Digital Drawing Canvas

A full-screen digital canvas for drawing and painting. Draw with your mouse or touch screen. Built with React, Next.js, and p5.js.

Features

  • Full-screen drawing canvas
  • Mouse and touch screen support
  • Adjustable brush size (1-50px)
  • Color picker for custom colors
  • Clear canvas functionality
  • Save drawings as PNG images
  • Responsive design for all devices

Technology Stack

  • React 19 with TypeScript
  • Next.js 15 for server-side rendering
  • p5.js for graphics and drawing
  • Tailwind CSS for styling
